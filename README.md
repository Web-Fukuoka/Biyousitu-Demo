# atelier kinari（美容室デモサイト）

ばってんらぼ 制作実績用のデモサイトです（架空の店舗）。
HTML / CSS / 素のJavaScript のみ。ビルド不要で GitHub Pages にそのまま置けます。

## フォルダ構成

```
index.html      トップ（FV・4点サマリー・コンセプト・約束・季節・料金・スタイル・スタッフ・口コミ・FAQ・アクセス・予約）
menu.html       メニュー・料金
gallery.html    ヘアスタイル一覧（長さ・メニューで絞り込み）
staff.html      スタッフ紹介（指名予約・担当スタイル）
access.html     アクセス・営業時間
reserve.html    ご予約方法・来店の流れ・FAQ
404.html        見つからないページ
assets/css/style.css     デザイン（色・書体・余白は先頭の :root に集約）
assets/js/site-data.js   店舗情報（★ここを書き換えるだけで全ページに反映）
assets/js/main.js        共通パーツの描画と動き
assets/img/              OGP画像・ファビコン
```

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作成（例：`kinari-demo`）
2. このフォルダの中身をすべてアップロード（`index.html` がリポジトリ直下に来るように）
3. リポジトリの **Settings → Pages** で Source を `Deploy from a branch`、Branch を `main` / `/(root)` にして保存
4. 1〜2分後、`https://ユーザー名.github.io/kinari-demo/` で公開されます

リンク・素材はすべて相対パスなので、サブディレクトリ公開でも崩れません。

## 別のお店に作り替える（販売時の手順）

1. **店舗情報**：`assets/js/site-data.js` の店名・住所・電話・営業時間・メニュー・スタッフ・ギャラリー・FAQ・予約URLを書き換え
2. **配色・書体**：`assets/css/style.css` 先頭の `:root`（ライト）と2つのダーク用ブロックの色を変更。書体は `--f-latin / --f-head / --f-body` と各HTMLの Google Fonts の行を変更
3. **写真**：site-data.js の `image` に Unsplash の photo ID（`photo-xxxx`）か、`./assets/img/salon.webp` のような相対パスを入れる。HTML内に直接書いた写真（ヒーロー・コンセプト・CTA背景）は各HTMLの `<img>` を差し替え
4. **title / description / OGP**：各HTMLの `<head>` を店名に合わせて修正。OGP画像は `assets/img/ogp.png`（1200×630）を差し替え
5. **地図**：access.html にコメントで Google マップ埋め込みのコードを入れてあります。必要ならコメントを外す

## デザイン（2026-10 リニューアル）

コンセプトは「光と空気をまとう、静かなラグジュアリーサロン」。

- 配色：Base `#F7F3EE`（60%）／Sub `#8C7B6E`（30%）／Accent `#C9A9A6`→`#D8C3A5` のグラデーション（10%）。予約ボタンだけにアクセントを使用
- 書体：欧文見出し Playfair Display／和文見出し Shippori Mincho／本文 Inter＋Noto Sans JP／数字 Cormorant Garamond
- 質感：画面に固定された淡いオーロラ（ゆっくり形を変える光）、フィルムのような粒子、ヘッダー・料金の補足・予約カード・スマホの予約バーにすりガラス
- 動き：ボタンはホバーで拡大・押すと縮む（0.3秒）、見出し→本文→ボタンの順に少しずつ遅れて浮かび上がる、ヒーロー写真はズーム後もゆっくり動き続ける、スタイル写真はホバーでゆっくりズームしてスタイル名が浮かぶ
- 料金：表（table）形式。指名料・ロング料金は表の下の「料金について」に記載
- 電話番号：ヘッダーのメニュー・フッター・予約帯・スマホの予約バーからタップで発信

## 入っている動き

- 初回訪問時のオープニング（ロゴが立ち上がって幕が上がる）
- ヒーロー：写真のゆっくりズーム、店名のせり上がり、縦書きコピーが1文字ずつにじみ出る
- スクロールで写真が下から開くように現れる／文章がふわっと表示
- 写真のゆるいパララックス、流れる英字の帯
- ヘッダー：スクロールで背景がつき、下にスクロールすると隠れる
- スマホ：円形に広がるメニュー、ヒーローを過ぎると下部に予約バーが出る
- 料金タブ（下線がスライド・キーボード操作対応）、ギャラリー絞り込み、口コミの自動切り替え、FAQの開閉

OSの「視差効果を減らす」設定がオンの人には、動きを止めて表示します。

## 実店舗で差し替えが必要なもの

- 予約URL（`site-data.js` の `reserve`）。デモではクリックすると「実際には移動しません」と表示されます
- スタッフ写真・スタイル写真は必ず実店舗の写真に（理由は CREDITS.md 参照）
- 口コミは実際のお客様の声に
- フッターの「制作サンプル」表記を削除（`demoNotice`）
